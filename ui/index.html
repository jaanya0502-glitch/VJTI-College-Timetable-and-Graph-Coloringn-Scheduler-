File formats

Scheduling method

Graph & Checks

Every class is a node. An edge connects sessions that cannot happen at the same time.

How graph colouring builds a timetable

DSATUR places the most constrained session first. Faculty, division, batch, and room rules define which sessions conflict, while the independent validator checks the finished weekly schedule.
